## 一、這個資料夾在做什麼

一套從「網路討論」到「溝通訊息」的流程，每一步都有對應的程式：

```
PTT 汽車版文章
  │ ① ptt_scraper.py         爬文章：用關鍵字搜尋，只留有提到 Lexus 的
  ▼
data/ptt_lexus.jsonl（1,589 篇）
  │ ② label_with_gemini.py   Gemini 逐篇閱讀、填一張固定的評分表
  ▼
data/labels.jsonl / labels.csv
  │ ③ check_label_quality.py 人工抽 200 篇，算 AI 與人工的一致率
  │ ④ categorize.py          把零散的抱怨歸成幾個大類
  ▼
data/labels_categorized.jsonl
  │ ⑤ analyze.py             統計、圖表、Persona 候選       → 產出 1
  ▼
out/ 資料夾
  │ ⑥ generate_messages.py   依 Persona 生成有依據的溝通訊息 → 產出 2
  ▼
out/messages.csv
```

## 四、目前的分析結果（第一版）

- 標註 1,589 篇，其中 **312 篇實質討論 Lexus 售後**，183 篇由車主發文
- 經驗發生地點：原廠 187 篇、外廠 10 篇，討論集中在原廠
- 車主發文中，**23.5%（43/183）已在猶豫或離開原廠**

**五個關鍵發現：**

1. **價格是最大的流失訊號**：最常見的不滿（99 篇）；提到價格的車主 44.9% 有流失傾向，是平均的 1.9 倍
2. **可能不是「貴」，而是「覺得被當盤子」**：有人說 Lexus 保養 CP 值高，也有人說「破 2 萬真是一頭肥羊」「自備機油卻收原廠機油錢」。**待 B 讀原文確認**
3. **等待很常被抱怨，但很少讓人離開**：提到等待的車主只有 11.1% 有流失傾向，遠低於平均
4. **車齡越高越容易離開**：0–3 年 15.5% → 3–5 年 18.8% → 5–10 年 27.3% → 10 年以上 55.6%（10 年以上只有 9 篇，僅供參考）
5. **二手車主風險是新車的 2.6 倍**：二手 31.4%、新車 12.2%

另外，經銷商信任問題有 107 篇，2026 年 8 月（國都購車糾紛）達高峰。

**Persona 建議（待兩人確認）：**

| Persona | 特徵 | 觸發時機 | 溝通重點 |
| --- | --- | --- | --- |
| 保固後精算型（主要對象） | 車齡 5 年以上，多為 ES、IS | 保固到期前 90 天 | 價格透明：事前報價、白話說明每個項目 |
| 二手入主型 | 買二手 Lexus，與經銷商無關係 | 過戶後第一次聯繫 | 歡迎加入、首次車況健檢、專屬顧問 |
| 新車守護型（預防） | 0–3 年新車，多為 NX、UX | 第一次保養後 | 用每次保養建立信任 |

**簡報要說明的限制**：網路聲量不等於全體車主；數據是相關不是因果；不少文章車齡、購車方式不明；少於 5 篇的組別不下結論；Mobile01 禁止自動抓取，所以只用 PTT。

## 五、`labels.csv` 欄位說明

| 欄位 | 意思 |
| --- | --- |
| `title`、`url`、`published` | 標題、原文連結、發文時間 |
| `n_comments` | 推文數 |
| `relevant` | 是否實質討論 Lexus 售後（TRUE／FALSE） |
| `dealer_trust_issue` | 是否涉及經銷商或原廠體系的信任問題 |
| `speaker` | 發文者：現任車主／前車主／潛在買家／非車主或不明 |
| `purchase_type` | 新車／二手／不明（只對車主判斷） |
| `car_models`、`car_age_years`、`mileage_km` | 車型、車齡、里程 |
| `sentiment` | 對 Lexus 售後的情緒：正面／中立／負面 |
| `stance_to_dealer` | 對原廠保養維修的立場：忠誠／猶豫／已轉外廠／未提及 |
| `experience_at` | 經驗發生在：原廠／外廠／兩者都有／不明（北都、國都等授權經銷商都算原廠） |
| `pain_points` | 對保養維修的具體不滿 |
| `churn_reasons` | 發文者離開原廠的原因 |
| `alternatives` | 提到的替代選項：外面保養廠、連鎖保養、副廠零件、自行保養等 |
| `comments_churned`、`comments_loyal` | 推文中自述「已改去外廠」「一直回原廠」的則數 |
| `comment_churn_reasons` | 推文中說離開原廠的原因 |
| `evidence_quote` | AI 判斷依據的原文 |
| `summary` | 一句話摘要 |

## 七、如果 B 也想自己跑程式

在 A 的電腦以外執行，需要先裝 Python 3.10 以上，並申請自己的 Gemini API 金鑰。在資料夾裡開 PowerShell：

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt matplotlib
$env:GEMINI_API_KEY = "自己的金鑰"
$env:PYTHONUTF8 = "1"
```

不需要 API 的程式（`analyze.py`、`check_label_quality.py`）不用金鑰也能跑。
