# T-104 標註品質比對：分歧表 + 三組一致率報告

分支：feat/t-104。不要執行任何 git 指令。只改 `lexus_kit/check_label_quality.py`（可新增函式），並產生下列輸出檔。

## 背景
同一批 60 篇有三份標註：
- Gemini：`lexus_kit/data/labels.jsonl`（`relevant` 是 bool，`sentiment`，`stance_to_dealer`）
- Codex：`lexus_kit/data/codex_labels.csv`（`id,relevant,sentiment,stance,note`，值已是中文）
- 人工：`lexus_kit/data/review_sheet.csv`（`human_relevant,human_sentiment,human_stance`；可能是 utf-8-sig 或 cp950，沿用 `score` 的讀法）

鐵則：程式不得把 AI 的值寫進任何 `human_*` 欄位；不得修改 `review_sheet.csv`。

## 要做的事
1. 新增子指令 `disagree`：
   ```
   python check_label_quality.py disagree --labels data/labels.jsonl --codex data/codex_labels.csv --out data/disagreements.csv
   ```
   - 只取 codex_labels 中的 id；Gemini 的 relevant 轉成 是／否。
   - 輸出三欄任一不同的列，欄位依序：
     `id,url,title,diff_fields,gemini_relevant,codex_relevant,gemini_sentiment,codex_sentiment,gemini_stance,codex_stance,codex_note,adjudicated_relevant,adjudicated_sentiment,adjudicated_stance`
     - `diff_fields`：不一致的欄位名，以「、」連接（是否相關、情緒、對原廠立場）
     - 三個 `adjudicated_*` 留空給 Ino 填
     - 不要輸出 Gemini 的 `summary` 或任何 `human_*` 欄位（避免影響裁決）
   - 若 `--out` 已存在且有任何 `adjudicated_*` 已填，**不得覆蓋**，印出警告後結束（保護人工裁決）。
   - UTF-8 with BOM。印出分歧列數與各欄分歧數。
2. 擴充 `score`：新增選用參數 `--codex`、`--disagree`、`--md`。
   - 沒給新參數時行為與現在完全相同。
   - 給 `--codex` 時，對三個欄位分別計算並印出：Gemini vs 人工、Codex vs 人工（只算人工有填的列）、Gemini vs Codex（全部 60 列）；每個數字附 n。
   - 給 `--disagree` 時，統計已裁決的分歧列：裁決結果與 Gemini 相同、與 Codex 相同、兩者皆不同 各幾筆（每欄分開）。
   - 給 `--md <路徑>` 時，把上述結果寫成 Markdown：標題「標註品質報告」、產生日期、資料說明（三份標註的來源與 n）、三組一致率表（欄位 × 比較組，格式 `85%（n=60）`）、各欄 Gemini vs 人工的混淆表、分歧裁決統計（若有）。報告中人工與 AI 一致率必須分開列，不得合併或混稱。
3. 檔頭 docstring 補上新子指令的用法。

## 驗收（在 `lexus_kit/` 下執行並把輸出貼進結果檔）
```bash
python check_label_quality.py score --sheet data/review_sheet.csv --labels data/labels.jsonl   # 舊行為不變
python check_label_quality.py disagree --labels data/labels.jsonl --codex data/codex_labels.csv --out data/disagreements.csv
python check_label_quality.py score --sheet data/review_sheet.csv --labels data/labels.jsonl --codex data/codex_labels.csv --disagree data/disagreements.csv --md out/label_quality.md
python check_label_quality.py disagree --labels data/labels.jsonl --codex data/codex_labels.csv --out /tmp/t104_test.csv && python -c "import pandas as pd; print(len(pd.read_csv('/tmp/t104_test.csv', encoding='utf-8-sig')))"
```
另外手動驗證覆蓋保護：複製 disagreements.csv 到暫存檔、在一格 `adjudicated_relevant` 填「是」，對暫存檔再跑 `disagree`，確認不會覆蓋（驗完刪除暫存檔）。
