# T-103 Codex 獨立標註 60 篇（第二位標註者）

分支：feat/t-103。不要執行任何 git 指令。

## 目的
同一批 60 篇 PTT 貼文已由 Gemini 標註、由人工標註。你是**第三位、獨立**的標註者，用來計算「雙 AI 一致率」。
獨立性是這個任務唯一的價值：只要看過其他人的答案，結果就作廢。

## 需要讀的檔案
- `lexus_kit/data/t103_ids.txt`：要標的 60 個 id（一行一個）
- `lexus_kit/data/ptt_lexus.jsonl`：原文（欄位 `id, title, published, content, comments`）
- `tasks/T-103_rules.md`：判斷規則（已從 `label_with_gemini.py` 原樣摘出，不需要再去讀那支程式；就算讀了也不會作廢，因為程式裡沒有任何標註答案）

## 禁止讀取（只有讀到這些才作廢）
- `lexus_kit/data/labels.jsonl`、`labels.csv`、`labels_categorized.jsonl`、`test_labels*`
- `lexus_kit/data/review_sheet.csv`、`review_sheet.csv.bak`（含人工答案與 Gemini 摘要）
- `lexus_kit/out/` 底下任何檔案
- 不得呼叫 Gemini 或任何外部 API

## 怎麼標
- **逐篇閱讀標題、內文與推文後親自判斷。** 不得寫關鍵字規則或程式自動判斷；程式只能用來讀取原文和寫出 CSV。
- 推文太多時至少讀前 80 則（與 Gemini 看到的範圍相近）。
- 三個欄位，規則以 `tasks/T-103_rules.md` 為準：
  - `relevant`：是／否（是否實質討論 Lexus 售後；推文中有具體售後內容也算）
  - `sentiment`：正面／中立／負面（對 Lexus 售後的整體情緒；與售後無關時填 中立）
  - `stance`：忠誠／猶豫／已轉外廠／未提及（只有發文者是現任或前車主、且談自己的保養維修去處時才填前三者）
- 另加 `note` 欄：一句話說明判斷依據，30 字以內；拿不準的在開頭寫「[不確定]」。

## 輸出
`lexus_kit/data/codex_labels.csv`（UTF-8 with BOM），欄位依序：`id,relevant,sentiment,stance,note`，60 列，順序同 `t103_ids.txt`。

## 驗收
在 `lexus_kit/` 下執行並貼上輸出：
```bash
python3 -c "
import csv
ids=open('data/t103_ids.txt').read().split()
rows=list(csv.DictReader(open('data/codex_labels.csv',encoding='utf-8-sig')))
assert [r['id'] for r in rows]==ids, 'id 不符或順序不同'
assert all(r['relevant'] in ('是','否') for r in rows)
assert all(r['sentiment'] in ('正面','中立','負面') for r in rows)
assert all(r['stance'] in ('忠誠','猶豫','已轉外廠','未提及') for r in rows)
from collections import Counter
for k in ('relevant','sentiment','stance'): print(k, dict(Counter(r[k] for r in rows)))
print('不確定', sum(r['note'].startswith('[不確定]') for r in rows))
print('OK', len(rows))
"
```
