# T-102 結果

## 修改檔案

- `lexus_kit/collector/capture.js`：列表按書籤後將 `{url,title}` 去重合併至目前網站 origin 的 `localStorage.lexus_queue`，保留 `lexus_done`；Mobile01 文章頁捲動至頁高穩定後擷取；每個 Mobile01 頁面仍需手動按書籤，串的最後一頁及 Dcard 存檔後更新完成標記、顯示進度並延遲 2 秒前往佇列下一篇。導頁提示提供「停止自動跳轉」鈕。新頁載入時不會自動擷取。
- `lexus_kit/collector/build_bookmarklet.py`：新增生成器，去掉說明註解與行首縮排後 URL 編碼輸出 bookmarklet，不改動 JavaScript token。
- `lexus_kit/collector/bookmarklet.txt`：依生成器重產。
- `lexus_kit/collector/README.md`：修正書籤安裝位置說明，更新佇列及逐篇手動觸發流程，移除過時圖表註腳提醒。

## 驗收

在 `lexus_kit/` 執行：

```text
python collector/build_bookmarklet.py
python 驗證 bookmarklet.txt 的 javascript: 前綴、URL decode 結果和 capture.js 去註解／縮排後內容
輸出：bookmarklet decode matches capture.js after documented compression: 7209 characters
node --check collector/capture.js
輸出：PASS（無語法錯誤）
node --check /tmp/t102-bookmarklet.js
輸出：PASS（解碼後無語法錯誤）
```

邏輯檢視確認：列表佇列以 URL 去重；進度以佇列網址或 Mobile01 thread／Dcard id 對照 done；Mobile01 非最後頁不標記完成，最後頁才找下一串；Dcard 存檔後標記完成；自動跳轉計時器檢查取消旗標。未使用背景抓取、UA 偽裝或防護繞過。

## 未能實測／疑慮

- 未在真實 Mobile01／Dcard 網頁執行書籤，無法確認網站目前 DOM、懶載入行為、分頁連結選擇器及瀏覽器下載提示；依任務限制未連線測試網站。
- `localStorage` 佇列依網站 origin 分開保存，需在對應網站頁面按列表書籤建立該站佇列。導頁後仍要使用者按書籤才擷取。
- 「停止自動跳轉」僅能在提示出現後、2 秒計時結束前按下。
