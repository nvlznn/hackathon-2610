# 競賽資訊（整理自官網 ht-hackathon.tw，2026/10/10）

## 題目：AI 流失風險洞察與智慧溝通：打造 Lexus 車主忠誠度的終極防線
- 系統：「潛在流失風險洞察與智慧溝通規劃系統」，探索台灣主流網路社群（如 PTT、Dcard、Mobile01 等）。
- 需涵蓋「服務體驗」與「零件保修」的自動化標籤與語意分析。
- 任務一：描繪顧客樣貌 → 用 NLP 建 Persona。
- 任務二：剖析與辨識風險因素 → 替代選項、最在意的考量點、高風險族群輪廓，並建立潛在流失風險辨識機制。
- 最終：設計能傳遞「Lexus 原廠服務價值」的溝通內容、接觸點策略與產品方案。
- 目標使用者：Lexus 售後服務部門的決策者。
- 產出 1：AI 網路輿情洞察系統架構與報告（Persona、高風險議題、整體市場輿情、使用了哪些 AI 技術／模型）。
- 產出 2：針對目標 Persona 的 AI 溝通計畫與系統流程（核心溝通策略、AI 生成內容範例、精準接觸點規劃、運作流程圖），須包含具流失風險或低黏著客群。
- 解題資源：Lexus 官網保修服務網頁、車主權益手冊（作為 AI 生成內容的基礎知識）；論壇資料自行蒐集。資源信件在步驟一報名後次一個工作日 17:00 前寄出（留意垃圾信件匣）。
